# Heroe App

Aplicación de heroes de Marvel y DC Comics, donde podrás buscar y ver los detalles de cada héroe. La aplicación se basa en la creación de una interfaz de usuario amigable y fácil de usar, donde el usuario puede buscar a los héroes por nombre y ver sus detalles en una tarjeta

## Características

- Login
- Logout
- Buscador de héroes por nombre
- Tarjetas de héroes con imagen, nombre, alter ego, publicador y primera aparición
- Detalles de cada héroe con sus características
- Ruta de navegación para ver los detalles de cada héroe

## Estructura del proyecto

El proyecto se encuentra estructurado de la siguiente manera:

- `src`: Contiene el código fuente de la aplicación
- `src/auth`: Contiene los componentes y las rutas de la aplicación relacionadas con la autenticación
- `src/heroes`: Contiene los componentes y las rutas de la aplicación relacionadas con los héroes
- `src/heroes/data`: Contiene la información de los héroes en formato JSON
- `src/heroes/helper`: Contiene las funciones de ayuda para el manejo de los datos de los héroes
- `src/heroes/pages`: Contiene las páginas de la aplicación relacionadas con los héroes
- `src/heroes/types`: Contiene los tipos de datos de los héroes
- `src/ui`: Contiene los componentes de la interfaz de usuario
- `vite.config.ts`: Contiene la configuración de vite para el proyecto

## Uso

Para visualizar el proyecto localmente, sigue estos pasos:

1. Clona este repositorio:

```
git clone https://github.com/JMatochePascual/Heroe-app.git
```

2. Navega al directorio del proyecto:

```
cd Heroe-app
```

3. Instala las dependencias necesarias:

```
npm install
```

4. Inicia el servidor en modo desarrollo:

```
npm run dev
```
